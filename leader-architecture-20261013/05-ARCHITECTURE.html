5. Quy trình kiến trúc triển khai DBTool

13/10/2026. Bản đặc tả để triển khai trong solution hiện tại. Tên type mới bên dưới là đề xuất, chưa phải API đã tồn tại. Dùng các record/planner hiện có nếu đáp ứng cùng hợp đồng. Không tạo pipeline thứ hai. Các quyết định NR trong tài liệu04 được kiểm bằng gate; junior không tự đặt số thiếu nguồn. Việc còn chờ quyết định có đầu ra lỗi cụ thể, không có nhánh “xử lý sau”.

5.1. Ranh giới module và luồng

Sơ đồ Mermaid có thể sao chép
flowchart TD
  A[Excel bytes + SourceRefs] --> B[S1 RawProjectInput]
  T[Template bundle + hashes] --> C[S0 AssetRegistry]
  R[Approved RuleRegistry] --> D[S2 EffectiveInput + Datums]
  B --> D
  C --> D
  D --> E[S3 Geometry + Assembly + Openings]
  E --> F[S4 Physical occurrences + CanonicalSchedule]
  F --> G[S5 PresentationGroupRegistry]
  E --> H[S6 Projection + Targets]
  G --> H
  H --> I[S7 Annotation + Dimensions]
  G --> J[S8 NativeTK + Bending intents]
  C --> I
  C --> J
  I --> K[S9 SheetPlan + FrameRegistry]
  J --> K
  K --> L[S10 Native DWG + Readback]
  L --> M[S11 Batch / Plot / PDF comparison]
  M --> N[Semantic + Visual verdict per case]

Domain giữ geometry/rebar/canonical quantities thuần .NET. Drawing giữ group trình bày, projection, annotation, native intents và layout; không tính lại geometry từ Excel. Application điều phối, kiểm capability/approval và giữ receipts. Infrastructure.Excel đọc snapshot bytes. AutoCAD chỉ import/render/readback trong host context. UI và Headless tạo cùng request, không có default scale/mode/identity riêng làm đổi kết quả. Project references giữ như ma trận03, không cho Domain tham chiếu Drawing/AutoCAD.

Mọi phase trả StageResult<T>; chỉ payload đã qua gate được chuyển sang bước phụ thuộc. Preview cho phase độc lập được phép nhưng phải mang trạng thái Partial. Gate Final luôn chặn nếu phase bắt buộc còn unresolved.

Station lưới (EX062 + BarDistributor hiện có, công thức hình học đề xuất từ ngữ nghĩa):

q = surfaceCover + diameter/2          // surface semantics, NR01 riêng hole
usable = span - 2*q
if usable<0: Block(DISTRIBUTION_NO_CLEAR_SPAN)
if usable==0:
    validate physical bar constructability; return single station at q
k = Equalized ? ceil(usable/requestedPitch) : floor(usable/requestedPitch)
if k exceeds supported integer count: Block(DISTRIBUTION_TOO_MANY_BARS)
if k==0:
    validate physical bar constructability; return single center station at span/2
gap = Equalized ? usable/k : requestedPitch
first = Equalized ? q : q+(usable-k*gap)/2
emit i=0..k, stationIndex from original host origin
last Equalized station = span-q; retain requested and actual gaps

Không nhận rounding k tùy tiện vì float; tolerance numerical lấy approved policy, không thêm fixture threshold. Catalog Ø giảm cấp theo danh sách có nguồn. Layer-stack/móc cần NR19 khi code chỉ dùng test-only convention. Hook nominal KC=t−2c hoặc nD theo EX063; shape path, bend allowance và nominal/fabrication basis là việc riêng, không mặc định tổng số trên schematic là length.

Clip ngang qua circle (cu,cv,r):

if abs(v-cv)>r: no cut
if tangent: preserve according to approved topology tolerance; no zero-length removed piece
otherwise intersections u=cu±sqrt(r*r-(v-cv)^2)
clip against support and union of opening exclusion intervals, including depth ownership
retained intervals -> separate SegmentOccurrences, shared ParentId, endpoint opening roles
assert retained+removed = preclip straight run under same measurement basis

ExclusionR từ concreteCutout+clearance policy, không hardcode320/375/15; NR01 chặn khi basis chưa chốt. Với polygon/hộp, dùng segment/contour intersections và union intervals, không bbox. Gắn hooks một lần theo đúng policy của retained segment; nếu đoạn ngắn không đủ hook hoặc va thì HOOK_NO_ROOM, không vẽ thẳng nhưng cộng chiều dài móc.

Ties dùng stations gốc và approved Đều/Lệch/phase; chưa có arbitrary policy NR03 trả Partial đúng component. OFF theo pitch vượt kích thước được note cho phép, cần receipt suppression reason; không lấy zero tùy tiện làm OFF. C path 5 đoạn/4 bo R8 giữ riêng schematic. 5.17. Source ledger và điều kiện triển khai

05A input fields, 05B formula/constant register và 05C interfaces/record quyết định là phụ lục bắt buộc. Trường numeric/enum không được đổi loại bằng heuristic tên field.
